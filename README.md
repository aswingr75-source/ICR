💰 MoneyLens AI

MoneyLens AI is an AI-powered Indian Currency Recognition System developed using Teachable Machine, TensorFlow.js, HTML, CSS, and JavaScript. The application uses a webcam to detect and classify Indian currency notes in real time and displays the detected denomination along with confidence level and note information.

🚀 Features

- Real-time Indian currency recognition
- AI model trained using Teachable Machine
- Webcam-based note detection
- Confidence score display
- Currency value and color information
- Modern responsive user interface
- Deployable on GitHub Pages

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- TensorFlow.js
- Teachable Machine
- GitHub Pages

⚙️ How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Ensure the model files are placed inside the "model" folder.
4. Install the Live Server extension.
5. Right-click "index.html" and select Open with Live Server.
6. Click Start Detection and allow camera access.

🌐 Deployment

The project is deployed using GitHub Pages.

📸 Application Workflow

1. User starts the webcam.
2. The AI model loads.
3. Currency note is shown to the camera.
4. The model predicts the denomination.
5. The detected currency and confidence score are displayed.
